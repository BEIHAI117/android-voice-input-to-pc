## 二、修掉的 6 个 bug

### 🔴 1. 明文流量被 Android 拦截（致命，影响所有真机）

```
W PcClient: websocket failure: CLEARTEXT communication to 10.0.2.2
            not permitted by network security policy
```

**Android 9+（targetSdk ≥ 28）默认禁止明文网络流量**，`ws://` 和 `http://` 全部被拦。
App 的 targetSdk 是 35，又没有声明网络配置，所以 **WebSocket 从来就建立不起来**——
这与防火墙、WiFi、配对都无关。

**这极可能就是你在真机上看到「电脑未连接」的真正原因。**

修法：新增 `res/xml/network_security_config.xml` 允许明文（LAN 专用工具，载荷另有可选 NaCl 加密），
并在 manifest 挂上 `android:networkSecurityConfig`。

> 这个 bug 漏到交付环节是我的失职——它不需要模拟器就能预见，属于 targetSdk 的常识检查项。

### 🔴 2. ASR 设置永远存不上

`etApiBase` / `etApiKey` 用 `onFocusChangeListener` 保存，但 `TextInputEditText` 在
`TextInputLayout` 里**根本不会回调 focus change**，值永远写不进 SharedPreferences。
改成 `doAfterTextChanged`，文本一变就存。

### 🔴 3. `refreshUi()` 把设置改坏

同步单选框状态时 `isChecked = ...` 会触发 `OnCheckedChangeListener`，把 `asrEngine`
写成 `system` 甚至垃圾值。表现为"明明选了云端识别，长按还是走系统识别"。

修法：把 listener 抽成字段，同步期间 `setOnCheckedChangeListener(null)` 解绑，同步完再挂回。

### 🟡 4. ASR 引擎在服务启动时就固定

`asr = AsrFactory.create(settings)` 写在 `onCreate()`，改设置页要重启悬浮球才生效。
改成每次长按都新建引擎（顺带每次都是干净状态）。

### 🟡 5. 第一次说话必然误报「电脑未连接」

`if (!client.isConnected) { connect(); flash("电脑未连接") }` —— 连接是异步的，
首次永远失败，还把刚说的话丢了。改成**未连接时排队，握手成功后自动补发**。

### 🟡 6. CLI 调试参数被持久化

`--dry-run` 会写进 `config.json` 变成默认值，导致后续启动全都是 dry-run（不真的输入）。
改成调试参数只对当次生效。

## 三、模拟器环境（复现用）

```bash
# 工具链在 D:\android-toolchain（JDK 17 + SDK 35 + Gradle 8.9 + emulator + 系统镜像）
export ANDROID_HOME=/d/android-toolchain/sdk
export PATH="$ANDROID_HOME/emulator:$ANDROID_HOME/platform-tools:$PATH"

emulator -avd phonemic_api35 -gpu swiftshader_indirect -no-boot-anim -no-audio
adb install -r dist/PhoneMic-v0.2.0.apk

# 跑完整验收（开记事本当靶子，读回验证）
cd pc-agent
python scripts/mock_asr.py --port 8799 --text "你好这是来自模拟器的测试文本" &
python -m agent
python scripts/test_e2e_emulator.py --serial emulator-5554 --ball 97 650 \
       --expect "你好这是来自模拟器的测试文本"
```

要点：

- **`emulator -accel-check`** 是判断硬件加速的权威方法。本机 `VirtualizationFirmwareEnabled=False`
  是误导（Hyper-V 已占用 VT-x），实际 `WHPX is installed and usable`。
- 模拟器到宿主机用 **`10.0.2.2`**；`adb reverse tcp:8765 tcp:8765` 也可作备用通道。
- **Git Bash 会把 `/sdcard/...` 转成 Windows 路径**，导致 `uiautomator dump` 失败。
  用 `MSYS_NO_PATHCONV=1`。
- **软键盘弹出会把对话框顶上去**，写死坐标必然点错。每次从 `uiautomator dump` 实时算坐标。
- 后台进程用 Bash 工具的 `run_in_background`，`&` 会在工具调用结束时被回收。

## 四、模拟器无法验证的部分（需真机）

| 项 | 为什么模拟器测不了 |
|---|---|
| 真实语音识别质量 | 模拟器无真实麦克风输入 |
| vivo / OriginOS 后台限制 | 模拟器是原生 Android，没有厂商白名单 |
| 局域网直连（手机 ↔ 电脑） | 模拟器走 NAT（10.0.2.x），不经过路由器 |
| 同一 WiFi / AP 隔离问题 | 同上 |
| 电池优化对常驻服务的影响 | 模拟器不限电 |

**但可以确定的是**：App 的网络、配对、传输、注入、悬浮窗代码路径全部正常，
「电脑未连接」的代码级根因（cleartext）已经修复。你在真机上遇到的连不上，
在装 v0.2.0 后**很大概率直接就好**；如果仍不行，用 App 里的「测试电脑连接」按钮，
它会明确告诉你是网络不通还是别的原因。
